# Lovely Chile — sitio web

Sitio vitrina de **Lovely Chile by Katherine L.**, studio de extensiones de pestañas, manicura y perfilado de cejas en Providencia, Santiago.

> **Estado:** en desarrollo — etapa de prototipos de diseño.

## Objetivo

Que una clienta que llega desde Instagram entienda en menos de un minuto qué servicios hay, cuánto cuestan y cuál le conviene, y que termine escribiendo por WhatsApp con su elección ya hecha.

## Tecnología

- HTML, CSS y JavaScript, sin frameworks ni compilación.
- Sitio 100% estático, pensado primero para celular.
- Sin backend: el contacto ocurre por WhatsApp.
